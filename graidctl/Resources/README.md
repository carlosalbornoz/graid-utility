# Resources

The app's pictures (enclosure, status icons, app icon) are G-Technology's artwork from the
original Configurator, so they aren't in this repository. Copy them from your own copy of the
old app:

```sh
tools/fetch-artwork.sh "/path/to/G-RAID with Thunderbolt Configurator.app" [enclosure.icns]
```

Without them the app builds and runs normally and shows system symbols instead.
